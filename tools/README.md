# Tools Directory

Use this folder to track apps, websites, services, libraries, and utilities you use.

## Add a tool

1. Copy `tool-template.md`.
2. Rename the copy, for example `vscode.md`.
3. Record what it does, how you use it, and useful links.
4. Link to projects where you use it.
